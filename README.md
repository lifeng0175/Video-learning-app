# AI Video Learning Workspace

英語の動画を使って、語学と専門知識を学ぶためのアプリケーションです。

現在はPythonとStreamlitを用いて、個人開発のPoCとして制作しています。

## 概要

YouTubeなどの英語動画を視聴する際、知らない表現や専門用語を調べたり、重要な内容をメモしたりする作業に時間がかかります。

本プロジェクトでは、動画の視聴、字幕の確認、英語表現の学習、専門知識の整理を一つのアプリケーションで行えるようにすることを目指しています。

## 想定ユーザー

英語の講義や技術動画から専門知識を学びたい大学生、大学院生、エンジニアなどを想定しています。

## 現在の実装機能

- MP4 / WebM動画の読み込みと管理
- 動画の再生と一部形式の変換
- faster-whisperによる英語音声の文字起こし
- 字幕とタイムスタンプの生成・保存・表示
- 動画取り込み後の自動文字起こし設定

## 今後の予定

- 字幕をクリックして該当する動画位置へ移動
- AIによる英語表現・専門用語の解説
- Anki向け学習カードの作成
- Obsidian向け学習ノートの作成

## 使用技術

Python / Streamlit / faster-whisper / CUDA / FFmpeg / pytest
